# 광주 관광 활성화

작성일: 2026-11-12 · 웹 검색 기반. "미확인"은 근거를 찾지 못한 내용이다.

## 1. 한눈에 보기

- 광주는 **"노잼 도시"**라는 말을 듣는다. 관광객이 오긴 하는데 **오래 머물지 않는 것**이 핵심 문제로 꼽힌다.
- 광주시는 2025년을 **'광주방문의 해'**로 정하고 숙박·식음료 할인 등을 했다.
- 2025년 11월까지 방문객 약 **6,501만 명(전년보다 6.8% 증가)**, 숙박 방문자도 5.9% 늘었다는 보도가 있다. 집계 기준은 **미확인**이다.
- 2026년에는 전남·광주 통합 흐름 속에서 **남도를 하나의 관광권으로 묶자**는 논의가 나온다.
- 광주 관광객 평균 체류시간 통계는 **미확인**이다.

## 2. 지금 광주 관광의 문제

| 문제 | 내용 |
|---|---|
| 노잼 이미지 | "광주는 볼 게 없다"는 인식 |
| 스쳐 가는 관광 | 낮에 전남을 돌고 밤엔 다른 지역으로 빠져나가는 흐름이 반복된다는 지적 |
| 따로 노는 관광 | 광주비엔날레는 광주 안에서만, 전남 관광은 시·군별로 따로 운영 |
| 정보 부족 | 통합 관광앱에 전남 22개 시·군 정보만 있고 광주 5개 구 정보는 찾기 어렵다는 보도 |
| 일회성 우려 | 방문의 해 성과를 이어가는 게 과제 |

## 3. 광주가 가진 무기

| 분야 | 내용 |
|---|---|
| 미식 | 광주 7미(한정식, 보리밥, 오리탕, 떡갈비, 주먹밥, **상추튀김**, 육전), 광주미식주간 |
| 문화·예술 | 광주비엔날레 |
| 민주·역사 | 5·18 (주먹밥 나눔 이야기) |
| 스포츠 | 광주시가 내세우는 분야. 구체 자료는 **미확인** |

- 광주시는 방문의 해 때 **"민주·문화·미식·스포츠 도시"**를 내세웠다.

## 4. 나온 해결책 (기사·정책)

- 숙박·체험 할인으로 **하룻밤 묵게 하기**
- 관광 조례안 3건 발의 (체류시간 늘리기, 상권 살리기 목적. 2026년 9월)
- 공간을 새로 해석해 **"머물고 싶은 도시"** 만들기 (2025년 3월 토론)
- AI·의료·스포츠를 관광에 입히기 (2025년 12월 포럼)
- 광주 동구: 여행사 상품으로 온 다른 지역 유료 관광객이 1년 새 1,714명 → 약 4,000명 (2023년 기사)

## 5. 마케터 의견 (근거 아닌 아이디어)

- 광주 관광의 약점은 **밤**이다. 밤에 즐길 거리가 있으면 숙박으로 이어진다. **상추튀김 + 맥주 같은 야식**은 밤 관광에 딱 맞는 메뉴다.
- 관광객은 "여기서만 먹는 것"을 찾는다. 상추튀김은 **7미 중 '차별성' 부문**이라 이 수요에 맞다.
- 비엔날레·미식주간 같은 **행사 기간에 맞춘 메뉴·할인**이 현실적이다.
- 관광객은 지도앱으로 가게를 찾는다. 네이버·카카오맵에 **"광주 7미 상추튀김"**을 꼭 쓴다.
- 이 아이디어들의 효과는 모두 **미확인**이다.

## 6. 토론거리

1. 광주가 정말 "노잼"인가, 아니면 **알리는 게 부족한** 것인가?
2. 관광객을 늘리는 것과 **오래 머물게 하는 것** 중 무엇이 먼저인가?
3. 광주만 홍보할까, **전남과 묶어서** 홍보할까?
4. 작은 가게(상추튀김집)가 관광객을 잡으려면 **무엇부터** 해야 하나?
