# 광주에서 요즘 바이럴 되는 것

작성일: 2026-11-12 · 웹 검색 기반. "미확인"은 근거를 찾지 못한 내용이다.

## 1. 한눈에 보기

- 2026년 광주 바이럴의 주인공은 **창억떡 '호박인절미'**다. 기사들이 **"대전에 성심당이 있다면 광주엔 창억떡"**이라고 부른다.
- 계기는 유튜브 채널 '하말넘많'의 **광주 여행 브이로그**(2026년 3월). 아이유가 방문했다는 소식도 퍼졌다.
- 그다음은 **빵·디저트**(소금빵 오픈런), **골목 상권**(첨단 시리단길, 동명동, 충장로 홍콩골목)이다.
- 주의: 창억떡은 이제 **전국 KTX역에서 살 수 있다.** "광주 안 가도 된다"는 기사까지 나왔다.

## 2. 창억떡 (가장 큰 바이럴)

| 항목 | 내용 |
|---|---|
| 가게 | 60년 된 광주 향토 떡집. 본점은 북구 중흥동 |
| 대표 메뉴 | 호박인절미 |
| 계기 | 유튜브 '하말넘많' 광주 여행 브이로그 (2026년 3월) |
| 검색량 | 3월 네이버 예상 월 검색량 41만5천 건, 2월보다 280% 증가 (예상치) |
| 내비 검색 | 중흥 본점 내비게이션 검색 2만8,890건, 전년보다 340% 증가 (한국관광데이터랩) |
| 방문객 | 가게 측은 매장 방문객이 2배 넘게 늘었다고 밝힘 |
| 지역 효과 | 북구 외지인 관광 소비 7.3% 증가. 창억떡 때문인지 따로 잰 자료는 **미확인** |
| 광주시 대응 | 2026년 6월 한 달 광주송정역 대합실에 팝업 매장 |
| 현재 | 전국 KTX역에서 구매 가능 |

**마케터 해석**
- 검색은 280~340% 늘었는데 지역 소비는 7.3%만 늘었다. **관심은 폭발했지만 관광으로 다 이어지진 않았다.**
- 전국 KTX역에서 팔면서 **"광주에 가야 할 이유"가 오히려 줄었을 수 있다.** 성심당이 대전 밖에 거의 매장을 안 내는 것과 반대다. (성심당 매장 정책은 **미확인**)

## 3. 빵·디저트

- **무뜨** (매월동 소금빵): 확장 이전 후 오픈런, 품절
- **글라라** (일곡동)
- 광주신세계 SNS 인기 디저트 팝업 (2026년 10월): 피자설기, 불닭맛 치즈설기 등
- 2026년 3월 기사: "줄 서서 먹는 광주의 맛", 지역 관광 활성화 기대
