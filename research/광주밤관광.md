# 광주 밤 관광 (실제로 있는 것)

작성일: 2026-11-12 · 웹 검색 기반. "미확인"은 근거를 찾지 못한 내용이다.

## 1. 한눈에 보기

- 밤에 갈 곳이 **아예 없지는 않다.** 하지만 **흩어져 있고 약하다.**
- 광주시 스스로도 야간관광 기본계획을 아직 못 세웠다. 시의회에서 "2027년은 돼야 끝난다"는 비판이 나왔다 (2025년 10월).
- 지역 주민은 주말에 주로 백화점·쇼핑몰에서 시간을 보낸다는 기사가 있다. 광주에는 대형 복합쇼핑몰이 아직 없다.
- 밤에 확실히 사람이 몰리는 건 **기아 타이거즈 야구 경기**다.

## 2. 실제로 있는 밤 거리

| 장소 | 내용 | 확인 상태 |
|---|---|---|
| 기아 챔피언스필드 (북구 임동) | 경기 날 소비·유동인구·교통량이 크게 늘어난다. 2025 개막전 2만500석 매진 | 확인 |
| 국립아시아문화전당 (동구) | 밤에 건물 조명이 켜진다. 한국관광공사 **야간관광 100선** | 확인 |
| 동명동 카페거리 (동구) | 학원가에서 카페·식당 거리로 바뀜. 아시아문화전당 바로 옆 | 확인 |
| 월봉서원 '살롱드월봉' (광산구) | 야간관광 100선 | 확인 (운영 시기 미확인) |
| 1913송정역시장 (광산구) | 밤 10~11시까지 영업한다는 안내가 있음. 문화 야시장 행사를 연 적 있음 | 영업시간 최신 여부 미확인 |
| 대인시장 야시장 (동구) | 예전에 야시장으로 유명했다 | **2026년 운영 여부 미확인** |
| 사직공원 전망대 (남구) | 광주 야경 | 운영시간 미확인 |
| 수완호수공원 (광산구) | 여름밤 명소로 소개 | 확인 |

## 3. 광주시가 한 것

- **'야구광 트립'**: 야구 보러 온 사람에게 경기 전 동명동·아시아문화전당·무등산을 도는 투어. KTX·숙박비 할인도 함께 했다.
- 다만 이건 **경기 전** 시간을 쓰는 프로그램이다. 경기 **끝난 뒤**(밤 9~10시 이후)를 잡는 프로그램은 **미확인**이다.

## 4. 마케터 판단

- "광주는 밤이 재밌는 도시"라고 홍보하면 **거짓말**이 된다. 와서 실망하면 역효과다.
- 밤은 홍보할 **강점이 아니라 채워야 할 빈칸**이다.
- 지금 진짜 있는 밤 손님은 **야구 끝나고 나오는 사람들**이다. 이 사람들이 경기 끝나고 바로 집이나 숙소로 가는지는 **미확인**이다.
- 상추튀김 가게가 할 수 있는 일: 경기 끝나는 시간까지 문 열기, "야구 끝나고 상추튀김" 메뉴. 효과는 **미확인**이다.
